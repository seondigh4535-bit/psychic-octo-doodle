# 고양이 귀 비니 (Cat Ear Beanie)

Roblox 단단한(rigid) 모자 액세서리.

| 파일 | 설명 |
|---|---|
| `CatEarBeanie.fbx` | Studio 업로드용 메시 (텍스처 포함) |
| `CatEarBeanie.glb` | 같은 메시의 glTF 버전 (FBX가 안 될 때 사용) |
| `CatEarBeanie_texture.png` | 256×256 텍스처 |
| `preview_*.png` | 미리보기 렌더 (회색 머리는 참고용, 파일에 포함 안 됨) |
| `build.py` | 생성 스크립트 (`pip install bpy` 후 `python3 build.py`) |

- 삼각형: 2,144개 (제한 4,000)
- 크기: 약 1.55 × 1.61 × 0.97 stud

## Studio에서 테스트
1. 상단 **Avatar** 탭 → **Import 3D** → `CatEarBeanie.fbx` 선택 → 가져오기
2. **Accessory Fitting Tool** 열기 → 가져온 메시 선택 → 유형 **Hat**
3. 마네킹 머리에 맞게 위치·크기 조정 → **Generate MeshPart Accessory**
4. 마음에 들면 스크린샷을 보내 수정 요청, 완성되면 우클릭 → **Save to Roblox** 로 업로드
